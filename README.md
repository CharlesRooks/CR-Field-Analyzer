# CR Field Analyzer

A professional handheld wireless diagnostics platform based on the ESP32-S3.

## Hardware

- LILYGO T-Display S3 AMOLED Plus
- ESP32-S3
- 16 MB Flash
- 8 MB PSRAM
- 3000 mAh LiPo Battery
- External Dual-Band Wi-Fi Antenna

## Firmware

SentinelOS
